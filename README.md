# Kukuh Dwi Saputra — Portfolio (`kukuhdev.com`)

Full-Stack Web Developer portfolio built with **Vite**, **React 19**, and **Tailwind CSS v4**.

## Tech Stack
- **Framework**: Vite + React
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Hosting**: Cloudflare Pages
- **Domain**: `kukuhdev.com`

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Output directory: `dist`
